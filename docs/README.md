# Finly Architecture Documentation

Welcome to the Finly architecture documentation. This directory contains the foundational specifications and technical guidelines prepared during Phase 1 of development, prior to UI implementation.

These documents establish the architectural decisions necessary to build a scalable, maintainable, and enterprise-ready financial dashboard.

## Phase 1 Deliverables

1. **[Product Requirements Document (PRD)](../PRD.md)** - High-level goals, features, and business logic.
2. **[Project Architecture](./project-architecture.md)** - Folder structures and modularity principles.
3. **[Design System Foundation](./design-system-foundation.md)** - Tokens, spacing, typography, and component specs.
4. **[Development Standards](./development-standards.md)** - Coding conventions, git flow, and file naming.
5. **[Component Planning](./component-planning.md)** - Definitions of reusable atomic and complex components.
6. **[Route Planning](./route-planning.md)** - Public, protected, and nested routing architecture.
7. **[State Management Strategy](./state-management-strategy.md)** - Handling server vs. global vs. local state.
8. **[API Layer Strategy](./api-layer-strategy.md)** - Networking, interceptors, and DTO handling.

## Next Steps (Phase 2)
Implementation will commence only after the following assets are provided:
- Figma MCP Link
- Mockup UI (screen by screen)

At that point, these documents will serve as the technical blueprint for translating the UI into code.
